NOSTALGIA 19 --- Shoe Brand Website

A premium visual website concept for NOSTALGIA 19, a Gen-Z-focused
footwear brand identity built around a dark glassmorphism aesthetic,
liquid chrome surfaces, bubblegum-pink accents, and editorial
typography.

The uploaded project is a self-contained HTML artifact that renders a
React-based experience. The source includes React 18.3.1 and a Tailwind
CSS-generated utility layer. The visual system is built around the
NOSTALGIA 19 identity, packaging, merchandise, campaign, and retail
touchpoints.

🚀 Running the Project

Option 1 --- Open the uploaded HTML

If you are using the supplied self-contained HTML artifact:

Download or clone the repository.

Open the HTML file in a modern browser.

The page should render as a standalone React artifact.

Option 2 --- React Development Setup

For a proper development version:

npm install
npm run dev

Then open the local development URL shown by your terminal.

The exact npm scripts depend on how the project is converted into a
Vite/React application.
